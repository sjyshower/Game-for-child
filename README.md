### 模式一：🧟 死亡鬼屋・特警除殭 (第一人稱 3D FPS 光線槍)
* **經典哥德恐怖鬼屋背景 (Gothic Haunted Horror House)**：
  * 地平線矗立傳奇**庫里安莊園（Curien Mansion）恐怖鬼屋**：高聳入雲的哥德尖塔、午夜十二點鐘樓、殘破排煙斗、兩翼多扇跳動燭光與綠焰的拱形窗櫺！
  * 天空盤旋**成群夜飛蝙蝠**，兩側矗立伸向血月與夜空的**猙獰枯樹枯藤**；
  * 前景設有尖矛鐵鑄墓園柵欄、石柱石雕、點燃溫暖瓦斯火光的**哥德鑄鐵路燈**、傾斜十字架與刻著 `R.I.P.` 的古老墓碑群，以及地面緩緩飄蕩的**夜間墓園翻滾迷霧**！
  * 偶爾劃破夜空的**驚悚閃電（Lightning Flash）**將整座恐怖鬼屋照耀出冷冽青藍的恐怖輪廓！
* **四大擬真逼真殭屍圖像 (Authentic Arcade Zombie Figures)**：
  * 目標完全採用**生動豐富的擬真殭屍角色繪圖圖像**，包含 4 種截然不同的恐怖類型：
    1. 🧟 **腐爛行屍 (Rotting Walker)**：撕裂的深色西裝、露出蒼白肋骨的血紅胸膛、暴突獠牙與血痕、鮮紅發光的嗜血眼珠。
    2. 🧪 **生化毒異 (Toxic Mutant)**：殘破亮橘色防化服、全身劇毒綠斑毒瘡、滴落酸液的利爪、強烈黃綠放射光芒瞳孔。
    3. 💀 **古墓死靈 (Crypt Banshee / Mummy)**：纏滿陳舊撕裂繃帶的乾癟屍身、幽冥青紫魂火雙眸、隨風擺動的碎布與骨爪。
    4. 🩸 **狂暴屠夫 (Gore Butcher)**：碩大魁梧體型、染滿鮮血的皮圍裙、鋼釘縫合的猙獰巨顱、怒瞪金黃狂暴烈瞳。
  * **動態步姿與張牙舞爪**：雙腿前後交替踏步、下顎咆哮抽動、長有尖銳利爪的雙臂在第一人稱視角中向鏡頭直直撲抓而來！
* **解答刻印於手持古墓石碑 (不遮擋殭屍全身圖像)**：
  * 解答選項不再遮蓋殭屍身軀，而是由殭屍雙手自然端持**雕花古老墓碑／古墓銘牌**（位於下腹腰際），以純白 22px 粗體雕刻大字呈現，既保證文字清晰無比，又能將殭屍猙獰面容、血口、利爪等整尊視覺 target 完整展現！
  * 準心瞄準殭屍時，觸發 **`[ TARGET LOCKED ]`** 科技電子瞄準框與青綠螢光邊框，點擊即可精準爆頭除殭！
* **街機光線手槍與打擊感 (Arcade Light Gun)**：
  * 畫面下方配備第一人稱警用光線手槍，槍身隨準心即時跟隨瞄準；
  * 扣板機時觸發槍身後座力、槍口火光（Muzzle Flash）與強烈槍聲；
  * 擊中正解觸發**爆頭（Headshot）特效**，殭屍往後潰散倒地，並在 0.8 秒後自動切換下一關！
  * 連續答錯 2 次或超時，殭屍將對鏡頭揮出**血紅爪擊（Claw Slash）**，全螢幕劇震並扣除 1 次防彈防禦！

## 🔥 共同核心作戰機制

1. 🛡️ **街機科幻動態血條（三次耐受系統）**：
   - 頂部 HUD 裝載動態血條：
     - 滿血（3/3）：`100%` 霓虹青綠漸層。
     - 二血（2/3）：`66%` 戰術金黃警戒。
     - 殘血（1/3）：`33%` 緊急危險紅光閃爍跳動。
   - 同一題中若連續猜錯 2 次或超時被撞擊/撲襲，**立即扣除 1 格裝甲/防彈生命（-33%）**！三次耗盡將被迫撤退進入檢討。

2. 🧠 **答對題目智慧排除（避免重複練習）**：
   - 答對題目自動寫入記憶體，後續關卡不再重複出現，讓學童持續挑戰新題目；首頁提供「✨ 已熟練掌握題數」與隨時「🔄 重置題庫」功能。

3. 📝 **錯題複習完整收錄（曾答錯即納入）**：
   - 只要在作答過程中曾選錯任何一次（第 1 次猜錯、連續錯 2 次、超時被襲），結算時皆完整列入錯題複習清單，絕不遺漏任何薄弱知識點！

4. ⚡ **答對自動跳關**：
   - 命中正確目標時自動跳關（0.8 秒後切換下一波），完全不需手動按「下一關」，遊戲節奏緊湊流暢！

5. 🔊 **題目語音自動朗讀**：
   - 支援專屬遮罩語音提示（如「什麼忘」、「避什麼」），輔導學童正確注音讀音。
