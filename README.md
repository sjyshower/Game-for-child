## 🔥 共同核心作戰機制

1. 🛡️ **街機科幻動態血條（三次耐受系統）**：
   - 頂部 HUD 裝載動態血條：
     - 滿血（3/3）：`100%` 霓虹青綠漸層。
     - 二血（2/3）：`66%` 戰術金黃警戒。
     - 殘血（1/3）：`33%` 緊急危險紅光閃爍跳動。
   - 同一題中若連續猜錯 2 次或超時被撞擊/撲襲，**立即扣除 1 格裝甲/防彈生命（-33%）**！三次耗盡將被迫撤退進入檢討。

2. 🧠 **答對題目智慧排除（避免重複練習）**：
   - 答對題目自動寫入記憶體，後續關卡不再重複出現，讓學童持續挑戰新題目；首頁提供「✨ 已熟練掌握題數」與隨時「🔄 重置題庫」功能。

3. 📝 **錯題複習完整收錄（曾答錯即納入）**：
   - 只要在作答過程中曾選錯任何一次（第 1 次猜錯、連續錯 2 次、超時被襲），結算時皆完整列入錯題複習清單，絕不遺漏任何薄弱知識點！

4. ⚡ **答對自動跳關**：
   - 命中正確目標時自動跳關（0.8 秒後切換下一波），完全不需手動按「下一關」，遊戲節奏緊湊流暢！

5. 🔊 **題目語音自動朗讀**：
   - 支援專屬遮罩語音提示（如「什麼忘」、「避什麼」），輔導學童正確注音讀音。

## ☁️ Google Apps Script (GAS) 雲端題庫撈取設定

遊戲已全面升級支援透過 **Google Apps Script Web App** 動態撈取 Google 試算表題庫！試算表編輯後，遊戲每次啟動立即同步最新題目。

### 🚀 部署教學（只需 3 分鐘）

1. **開啟題目試算表**：
   打開您的 [Google 試算表](https://docs.google.com/spreadsheets/d/1QetCLW6afDNxsJCB8oD6IvYQc-ReItlkLn4lFSaSVYY/edit?usp=sharing)。
2. **開啟 Apps Script 編輯器**：
   點擊上方選單 **「擴充功能」 (Extensions)** > **「Apps Script」**。
3. **貼上專案程式碼**：
   將專案目錄中的 [google_apps_script.js](./google_apps_script.js) 程式碼整份複製並貼入編輯器（取代原有內容）。
4. **部署為網路應用程式**：
   - 點擊右上角 **「部署」 (Deploy)** > **「新部署」 (New deployment)**。
   - 點擊左側齒輪選擇種類：**「網路應用程式」 (Web app)**。
   - 說明：國小遊戲題庫 API
   - 執行身分 (Execute as)：**「我」 (Me)**
   - 誰可以存取 (Who has access)：**「任何人」 (Anyone)** ⚠️ *請務必選任何人，遊戲前端才能順利撈取*
   - 點選 **「部署」 (Deploy)**，若跳出權限請求請點選「核准存取權」。
5. **複製 Web App 網址**：
   複製生成的網址（結尾應為 /exec，例如：https://script.google.com/macros/s/.../exec）。
6. **於遊戲中套用**：
   - 打開遊戲 index.html，點選右上角 **「⚙️ 題庫設定」** 按鈕（或點選頂部的連線狀態膠囊）。
   - 將 Web App 網址貼入輸入框，點擊 **「⚡ 測試連線並儲存」**！
   - 系統會自動測試連線並將設定儲存於瀏覽器中，永久生效！

## 👤 學員 ID 登入與精通排除機制 (功能升級)

遊戲支援**多學員 ID 登入與進度切換**，精準掌握每位學童的學習成果：

1. **學員 ID 登入與快速切換**：
   - 首頁橫幅與頂部導覽列設有 **「👤 登入 / 切換 ID」** 按鈕。
   - 支援輸入學員暱稱/座號（例如：小明、Amy、Ray），系統自動獨立儲存每位學員的答題記錄。
   - 登入彈窗提供「歷史學員名單快速點選」，方便多位小朋友或兄弟姊妹一鍵切換。

2. **連續答對 2 次自動排除機制**：
   - 每一題目皆記錄作答狀況，**只要同一題目「連續答對 2 次」（且作答過程無失誤），系統即判定為「已熟練精通」**！
   - 下次進行遊戲時，**已精通的題目將自動從題庫中排除**，不再重複出現，讓學童專注練習不熟的題目！
   - 作答時若猜錯、超時或遭撲襲，該題的連續答對次數將重設歸零。
   - 首頁即時顯示【🏆 連續答對2次 (精通排除)】、【⚡ 連續答對 1 次 (差1次排除)】、【📊 累計作答】等詳細統計。

3. **專屬遊戲記錄重置**：
   - 首頁提供 **「🔄 重置此 ID 記錄」** 選項。
   - 點擊後跳出防呆確認視窗，確認後將清除該學員的所有連續答對次數與精通狀態，讓所有題庫題目重新開放挑戰！
